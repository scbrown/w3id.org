# /tallygraph/

Permanent identifiers for the Tallygraph stack's Quechua vocabulary.

- Namespace: `https://w3id.org/tallygraph/quechua/ns#`
- `quechua/ns` redirects to the Turtle catalog for `Accept: text/turtle`,
  otherwise to the HTML catalog. Explicit `quechua/ns.ttl` and
  `quechua/ns.html` select their respective representations.
- The root redirects to <https://github.com/tallygraph>.
